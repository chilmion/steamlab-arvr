# SteamLab AR/VR – Penyedia Steam
Media pembelajaran interaktif (AR/VR WebXR + Generative AI) untuk mata kuliah Utilitas Industri, bab Penyedia Steam.
Tanpa build: file statis (index.html, styles.css, app.js, scene.js, steam.js). Deploy ke GitHub Pages (Settings → Pages → branch main, folder / ).
Lokal: `python3 -m http.server 8765` lalu buka http://localhost:8765
GenAI: opsional kunci Gemini milik pengguna (tombol ✦ AI); tanpa kunci memakai mesin generatif bawaan.
